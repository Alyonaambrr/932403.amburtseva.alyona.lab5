# Личная страница «Предприниматель и стартапер» (ЛР №4, №5)

Учебный проект по веб-технологиям. Вариант 16. Автор: Амбурцева Алёна.

## О проекте

Одностраничный сайт-визитка в оранжево-белых тонах, объединяющий анализ дневной выручки (ЛР №4) и интерактивное управление списком бизнес-гипотез (ЛР №5). Вся логика реализована в одном скрипте `script.js`, состояние сохраняется в `localStorage` между перезагрузками.

## Структура проекта

- `lab_5.html` — главная страница (разметка)
- `lab_5.css` — стили (включая адаптивность и тёмную тему)
- `script.js` — единый скрипт с логикой ЛР №4 и ЛР №5
- `README.md` — описание проекта
- `images/photo.jpg` — фото автора

## Что реализовано

- **Поиск элементов:** `getElementById` (кнопки, контейнер, секция), `querySelector` (статус и текст внутри карточки), `querySelectorAll` (проверка дубликатов и подсчёт карточек).
- **Манипуляции с DOM:** `document.createElement`, `appendChild`, `remove`, изменение `textContent`, `classList.add/remove`, `dataset.status`.
- **Кнопка «+ Добавить гипотезу»:** через `prompt` запрашивает формулировку, создаёт карточку `<article>` с текстом, статусом «Не проверена» по умолчанию и кнопками действий. Проверяет дубликаты.
- **Кнопка «Изменить статус»:** переключает статус между «Не проверена» и «Проверена» с изменением цвета бейджа.
- **Кнопка «Удалить»:** удаляет конкретную гипотезу с анимацией исчезновения.
- **Переключение темы:** кнопка меняет класс `theme-light`/`theme-dark` у `<body>`, обновляя CSS-переменные.
- **Скрытие/показ:** кнопка «Скрыть гипотезы» добавляет/убирает класс `hidden` у секции.
- **Обработка ошибок:** проверка существования всех элементов перед манипуляциями (`if (!element) console.error(...)`), `try/catch` при работе с `localStorage`.
- **localStorage:** сохранение массива гипотез (`entrepreneur_hypotheses_v1`) и выбранной темы (`entrepreneur_theme_v1`), восстановление при `DOMContentLoaded`.

8. Нажмите «Тёмная тема» — страница переключится на тёмную схему.
9. Нажмите «Скрыть гипотезы» — секция исчезнет, кнопка сменит текст на «Показать гипотезы».
10. Перезагрузите страницу — все гипотезы и тема восстановятся из `localStorage`.
